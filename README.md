# Stjernerne - Evolutionary Astrology

Dedicated English evolutionary horoscope generator. All 17 planetary node pairs,
Porphyry/Placidus/Equal House/Regiomontanus/Whole Sign, secondary progressions,
true solar arc and exact relocated solar returns. Includes the clockwise polar
Regiomontanus correction, JSON save/import, interactive SVG and A4 print preview.

Docker builds the complete corresponding source in stjernerne-source.zip.
The running application serves this exact archive at /source. AGPL-3.0-or-later
with retained Swiss Ephemeris, font and GeoNames license notices.

Validated locally: 345 Python and 45 JavaScript tests. A dedicated Render Free
service is intended; verify workspace included quotas and $0 extra cost before
creation. No database, paid disk, new payment details or other service changes.

The app opens at / and /evolution. Container port 8765; health /api/health.
Render supplies RENDER_EXTERNAL_URL for origin checks. Browser saves remain local
to the browser. Free instances may sleep and are subject to workspace quotas.
